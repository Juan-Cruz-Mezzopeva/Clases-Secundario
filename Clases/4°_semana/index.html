Selectores, cascada y especificidad

Vas a completar estilos.css paso a paso. Cada vez que lo guardes y recargues esta página (F5), vas a ver el resultado acá mismo. Leé cada paso antes de escribir código — la idea no es adivinar, es predecir.

0

Conectar el archivo

Este HTML todavía no está conectado a estilos.css. Por eso, todo lo que hay dentro de la "zona a estilizar" de cada nivel se ve completamente plano — así se ve cualquier página sin CSS.

Hacé esto: abrí este archivo, andá al <head>, y agregá la línea que conecta estilos.css (está comentada ahí mismo, como pista).

Después, como primera prueba, escribí esta regla en estilos.css y recargá la página:

body {
  background-color: #f0f0f0;
}

💡 Por qué: si el fondo de la página cambia, ya sabés que el archivo está conectado. Si recargás y no cambió nada, revisá el <link> antes de seguir — no tiene sentido avanzar sin esto.

1

Nivel 1 — Selectores de etiqueta

Los dos elementos de abajo, un <h2> y un <p>, todavía no tienen ningún estilo propio.

Este es el título que vas a estilizar

Y este es un párrafo común, sin ninguna clase. Los dos se seleccionan solo por su etiqueta.

Hacé esto: en estilos.css, escribí una regla para h2 y otra para p, cada una con un color de texto distinto.

h2 { color: ???; }
p { color: ???; }

💡 Por qué: un selector de etiqueta afecta a todos los elementos de ese tipo en toda la página — inclusive a los que van a aparecer en los niveles siguientes. Guardalo en la cabeza para el Nivel 3.

2

Nivel 2 — Selectores de clase

Ahora hay tres párrafos seguidos. Solo uno tiene la clase destacado.

Este es un párrafo común, igual que en el nivel anterior.

Este párrafo tiene la clase "destacado".

Este es otro párrafo común, sin clase.

Hacé esto: escribí una regla .destacado que le cambie el background-color solamente a ese párrafo, sin tocar los otros dos.

.destacado {
  background-color: ???;
}

💡 Por qué: el selector de clase apunta solo a los elementos que la tienen, aunque compartan la misma etiqueta con otros que no. Además, si guardaste el Nivel 1, fijate que el color de texto del p { color: ...} también se sigue aplicando acá — las reglas se van sumando, no se reemplazan entre sí.

3

Nivel 3 — El desafío de especificidad

Este párrafo tiene la clase aviso. Fijate que también es un <p> — o sea que le pueden aplicar dos reglas distintas al mismo tiempo: una por etiqueta y otra por clase.

¿De qué color voy a quedar?

Hacé esto, en este orden — no te saltees pasos:

  1. Predecí primero, en tu cuaderno: si escribís p { color: blue; } y .aviso { color: red; } en estilos.css, ¿de qué color va a quedar este párrafo? ¿Te parece que importa cuál de las dos reglas escribas primero en el archivo?
  2. Recién ahora escribí las dos reglas en estilos.css y recargá la página para comprobar tu predicción.
  3. Invertí el orden de las dos reglas dentro del archivo (poné .aviso primero y p después) y recargá de nuevo. ¿Cambió el resultado?
  4. Escribí en tu cuaderno, con tus palabras, por qué ganó la regla que ganó.
p { color: ???; }
.aviso { color: ???; }

💡 Por qué: acá no gana el orden en el archivo — gana el selector que más "pesa". Una clase pesa más que una etiqueta, sin importar en qué línea esté escrita cada una.

Cuando termines los 3 niveles y hayas anotado tus respuestas del desafío, guardá estilos.css y hacé el commit:

init: conectar CSS y aplicar estilos base
