Bloque 1

Qué es CSS y cómo conectarlo

CSS le dice al navegador cómo mostrar el contenido HTML: colores, tamaños, espaciados y posiciones.

Selector de etiqueta

Aplica a todos los elementos de ese tipo.

p { color: red; }

Selector de clase

Aplica a todo elemento con ese class="".

.destacado { font-weight: bold; }

Selector de ID

Aplica solo al elemento con ese id="".

#titulo { font-size: 32px; }
Tarea 1

Abrí estilos.css y cambiá el valor de --color-primario. Guardá y mirá cómo cambia toda la página de golpe.

Bloque 2

El modelo de caja (box model)

Todo elemento HTML es una caja rectangular con cuatro capas: margin, border, padding y content.

margin
border
padding
content

Probá cambiar estos valores en estilos.css:

.bm-margin  { padding: 24px; }   /* margin */
.bm-border  { border: 4px solid; } /* border */
.bm-padding { padding: 24px; }   /* padding */
.bm-content { width: 120px; }    /* content */
Tarea 2

Inspeccioná esta sección con F12 → DevTools. Buscá el panel "Computed" y observá el diagrama del box model. Cambiá el padding de .boxmodel-demo desde ahí.

Bloque 5

Proyecto integrador

Aplicá todo lo aprendido. Cada etapa completada = un commit en Git.

  1. 01
    Conectar CSS externo

    Crear estilos.css y linkearlo en el HTML.

    git commit -m "init: agregar archivo CSS"
  2. 02
    Tipografía y colores

    Google Fonts + paleta con variables CSS.

    git commit -m "style: tipografia y colores"
  3. 03
    Box model

    Aplicar margin, padding y border a cada sección.

    git commit -m "style: box model aplicado"
  4. 04
    Layout con Flexbox

    Navbar y grilla de tarjetas con Flexbox.

    git commit -m "layout: navbar y grilla flexbox"
  5. 05
    Deploy en GitHub Pages

    Settings → Pages → Branch: main → Save.

    git commit -m "docs: sitio publicado en gh-pages"
