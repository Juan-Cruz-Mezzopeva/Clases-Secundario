Nivel 1 — Tipografía: comparar dos fuentes

Estos dos párrafos tienen exactamente el mismo texto, pero todavía ninguno tiene tipografía propia.

Este párrafo va a usar una tipografía con serifas (con "patitas" en las letras).

Este párrafo va a usar una tipografía de palo seco (sin "patitas").

Hacé esto: aplicale a .texto-a una fuente serif del sistema (por ejemplo Georgia, serif) y a .texto-b una sans-serif (por ejemplo Arial, sans-serif). De paso, dale a cada uno un font-size y un line-height distinto.

.texto-a { font-family: ???; font-size: ???; line-height: ???; }
.texto-b { font-family: ???; font-size: ???; line-height: ???; }

💡 Por qué: antes de importar una fuente externa, conviene notar cómo cambia la lectura solo con lo que ya viene instalado en cualquier computadora.

2

Nivel 2 — Los 3 formatos de color

Estos tres recuadros deberían terminar siendo del mismo color exacto, escrito de tres formas distintas.

nombre
hex
rgb

Hacé esto: elegí un color y escribilo de las tres formas. Por ejemplo, si elegís "purple": buscá su equivalente en HEX y en RGB (podés buscar "purple hex rgb" o probar con #800080).

.color-nombre { background-color: ???; } /* nombre */
.color-hex { background-color: ???; } /* #?????? */
.color-rgb { background-color: ???; } /* rgb(?, ?, ?) */

💡 Por qué: los tres formatos son intercambiables — lo que cambia es la precisión y qué tan cómodo es escribirlos. En la industria, HEX es el más común.

3

Nivel 3 — Importar una fuente de Google Fonts

Esta vez el título de acá abajo va a usar una fuente real, importada desde internet.

Este título va a cambiar de tipografía

Hacé esto, en este orden:

  1. Entrá a fonts.google.com, elegí una fuente que te guste y conseguí su <link> de importación.
  2. Pegá ese <link> en el <head> de este archivo (fijate el comentario que dejamos ahí como pista).
  3. En estilos.css, aplicale esa fuente a .titulo-google-font.
.titulo-google-font { font-family: '???', sans-serif; }

💡 Por qué: el <link> solo descarga la fuente — todavía hace falta decirle a algún elemento que la use con font-family. Son dos pasos, no uno.

4

Nivel 4 — Variables en :root

Vas a declarar tu paleta como variables, en vez de escribir los colores sueltos.

Este texto va a usar tu color primario.

Este texto va a usar tu color secundario.

Hacé esto: al principio de estilos.css, declará dos variables dentro de :root, y usalas con var() en los dos párrafos de arriba.

:root {
  --color-primario: ???;
  --color-secundario: ???;
}

.usa-variable-1 { color: var(--color-primario); }
.usa-variable-2 { color: var(--color-secundario); }

💡 Por qué: :root es el "punto más alto" del documento — una variable declarada ahí está disponible en cualquier regla de todo el archivo.

5

Nivel 5 — Propagación: cambiar una variable, ver 3 cambios

Estos tres elementos van a usar la misma variable de color, cada uno en una propiedad distinta.

Fondo con la variable

Texto con la variable

Borde con la variable

Hacé esto, en este orden:

  1. Creá una variable nueva, --color-acento, en :root.
  2. Usala en los tres elementos de arriba: como background-color, como color y como border-color respectivamente.
  3. Ahora cambiá solo el valor de --color-acento en :root (un color distinto) y recargá. Los tres elementos deberían cambiar juntos, sin tocar sus propias reglas.
:root { --color-acento: ???; }

.prop-caja { background-color: var(--color-acento); }
.prop-texto { color: var(--color-acento); }
.prop-borde { border: 3px solid var(--color-acento); }

💡 Por qué: esto es lo que en verdad ahorra tiempo — no es solo "menos para escribir", es poder cambiar todo un sistema de diseño editando una sola línea.

6

Nivel 6 — Integración: armá tu mini sistema de diseño

Última caja. Esta vez la única regla es: todo lo que uses acá tiene que venir de una variable, no de un valor suelto.

Tarjeta de identidad

Esta tarjeta debería usar tu tipografía de Google Fonts, tu color primario o secundario, y algún acento — todo a través de var().

Hacé esto: escribí una regla .tarjeta-identidad (y si querés, una para el h2 y el p de adentro) usando exclusivamente var(--...) para colores y tipografía. Podés combinarlo con lo que aprendiste de box model en la clase pasada.

.tarjeta-identidad {
  font-family: var(--???);
  background-color: var(--???);
  border: 2px solid var(--???);
  /* + padding, margin, etc. */
}

💡 Por qué: esta tarjeta es, en chiquito, exactamente el mismo tipo de decisión que van a tomar entre todos para el proyecto del curso: una identidad definida una vez y usada en todos lados.
